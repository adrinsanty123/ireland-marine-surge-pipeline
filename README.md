# Irish Coastal Storm Surge & Harbour Hazard Pipeline

Automated data acquisition and preprocessing pipeline collecting 5-minute coastal sea levels (`IrishNationalTideGaugeNetwork`), astronomical tide predictions (`IMI-TidePrediction`), and offshore weather buoy telemetry (`IWBNetwork`) across Ireland.
